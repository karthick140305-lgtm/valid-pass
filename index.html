Chennai One Web Prototype

An interactive, high-fidelity mobile prototype of the Chennai One transport app. Switch between pages using the phone's bottom navigation bar.

  • 1
    Live Pass Clock

    The date and time box on the Monthly Pass ticks live down to the second.

  • 2
    Interactive Validity Editor

    Navigate to the Profile tab, scroll down below Safety, and select a custom validity date. The pass updates instantly and persists across refreshes.

  • 3
    Verified User Portrait

    The official passport photo of the user in a yellow shirt is framed securely inside the pass.

  • 4
    Mock Pages

    Navigate between Home, Passes, Live status, Past Tickets, and Profile screens.
